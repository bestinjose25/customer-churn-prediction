# Customer Churn Prediction

Predicting which telecom customers are likely to cancel their subscription, using historical customer data — enabling proactive retention instead of reactive damage control.

## Problem

Customer churn is expensive: acquiring a new customer typically costs far more than retaining an existing one. This project builds a model that flags at-risk customers before they leave, so a business could prioritize retention efforts (discounts, outreach) toward the customers most likely to churn.
